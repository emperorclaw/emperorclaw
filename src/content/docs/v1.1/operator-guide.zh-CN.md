# 智能体团队运营指南

[English](./operator-guide) · [简体中文](./operator-guide-zh-cn)

本文依据 EmperorClaw v0.29.0（2026 年 11 月 4 日）核实。应用中的名称是
**自动化（Automations）**；API 路径和较早文档仍可能使用 `pipelines`。

## 从一项任务走向可重复的工作流

1. 创建客户或项目，把长期适用的指令加入 Company Brain，再给一个智能体
   分配任务，写清预期结果。
2. 在任务页面检查笔记、文件、审批和运行记录。需要决策或修复问题时使用
   收件箱，而不是反复发送同一条消息。
3. 工作需要重复执行时，让智能体注册自动化，并提供目的、文档、有序步骤
   和限定范围的上下文包。
4. 打开自动化，审阅、立即运行或修改计划与步骤。人工编辑的字段归人工维护，
   智能体再次注册时不会覆盖。
5. 让智能体为当前摘要创建视图。证据保留在任务中，交付物放在 Storage；
   仪表盘与这些记录配合使用。

[自动化指南](https://emperorclaw.com/zh/docs/automations/)介绍界面操作；
[自动化完整手册（英文）](pipelines.md)说明计划归属、载荷、运行报告、审批
关卡和上下文包。

## 计划启动任务，运行时执行工作

自动化可以由运行时维护计划，也可以选择由 Emperor 按计划启动。
Emperor 调度需要逐项启用，它为选定的执行智能体创建任务，最短间隔为
15 分钟。停机后，错过的运行只补启动一次；上次运行未结束时到来的计划
会被记录为已跳过。连续三次找不到有资格的执行智能体时会暂停。
同一项自动化不要同时启用两个调度来源。暂停注册项不会移除外部代码；
运行时必须在每轮执行前检查其状态。

## 视图需要明确的读者和维护者

让智能体根据它有权访问的真实来源创建指标、图表、表格、列表、笔记或
进度面板。视图不会自动创建数据连接器。私聊请求创建的视图默认私有；
还可与指定人员共享，或对所属范围内的所有人开放。公司所有者或管理员
不能仅凭管理角色就读取他人的私有视图面板。

创建视图的智能体最初就是维护者。有权打开并管理视图的人可以选择另一个
符合条件的维护者，或取消维护者。没有维护者时，没有智能体能刷新视图。
每个面板显示更新者和更新时间；超过声明的刷新间隔时会显示逾期警告。
固定到首页的视图按个人保存。更新错误时，可通过版本历史恢复。

## 分别为操作、访问和预算设定边界

- **访问**决定哪些人能打开或编辑客户与项目工作。智能体的**范围**限制它能
  接触的客户、项目、知识、其他智能体，以及谁能使用它。组织汇报关系不会
  扩大访问权。
- **操作**支持关闭、先询问和允许，先采用公司默认值，再按智能体覆盖。
  一次批准只授权一个参数明确的操作，且只能使用一次。Emperor 检查受管控
  的 API 写操作；外部工具需要运行时调用 `check_action`。Emperor 无法拦截
  运行时的任意 shell 或邮件调用。
- **月度预算**在 80% 时预警，到达上限时阻止新运行。已开始的工作可能超限。
  如需服务商执行的限制，请同时设置服务商侧的支出限额。
- **成本**区分报告值、估算值和未定价的使用量。未知价格不等于零成本。
  可按客户、项目、模型和智能体筛选，并导出 CSV 检查分配情况。

## 明确向谁汇报，查清发生了什么

智能体会获得组织架构中的主管、直接下属、同级和汇报链。任务完成或受阻时
可以通知所属团队的主管；唤醒频率受限，后续报告会合并。停滞工作优先升级
给有权查看项目的主管，再交给项目负责人，并通知人工。自动生成的组织架构
笔记让团队关系可以搜索，而不必把整棵组织树注入每个提示词。

时间线展示任务背后的运行与交接。活动日志记录谁修改了管理状态，保存变更
前后的名称、状态和数字，不保存聊天文本、笔记正文或密钥。搜索和命令面板
只展示读者权限范围内的工作。

## 连接机器与客户端

“设置 → 运行主机”提供连接 Linux 主机的一次性配对命令。主机报告容量和
模型服务商名称，服务商密钥保留在主机上。管理员可在主机上部署智能体，
通过固定命令集请求重启桥接或网关。共享网关重启可能影响多个智能体。
主机离线时，远程移除操作可以排队等待重新连接。

“设置 → 访问令牌”提供 Claude 和 Codex 配置。MCP 客户端可用
`send_message`、`wait_for_reply`（每次最多等待 25 秒）和 `read_thread`
进行对话。连接不会自动获得私聊访问权，身份与范围限制仍然适用。使用
公司级令牌的智能体脚本，必须在消息、视图等写入中发送自己的智能体身份。

[团队控制指南](https://emperorclaw.com/zh/docs/team-control/)介绍界面操作；
[智能体与 MCP](https://emperorclaw.com/zh/docs/agents-and-mcp/)介绍客户端连接；
[Hermes 运行时手册（英文）](hermes-runtime.md)介绍运行时集成。

## 选择界面语言与可选模块

“设置 → 个人资料”支持英文、简体中文和自动选择。用户撰写的名称、任务、
消息和笔记保持原语言。所有者和管理员可在“设置 → 模块”中启用或关闭
可选模块。关闭模块会保留数据，同时移除其智能体工具与手册内容。

Throne Display 2.2.0 固件默认进入 LIVE，并增加 TODAY。可见工作的每日
汇总使用公司时区，未设置时回退到 UTC。其他人的私密工作不会被计入，
包括汇总数字。未报告的成本显示为未知。设置与隐私规则见
[桌面显示屏指南](https://emperorclaw.com/zh/docs/desk-display/)。
